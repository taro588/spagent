# Windows 安装说明

Adobe 官方文档说明，Windows 7.2+ 的 Painter 用户资源目录默认为:
C:\Users\<用户名>\Documents\Adobe\Adobe Substance 3D Painter

Python 插件应位于:
...\python\plugins

本安装器将 SP AI Assistant 安装为:
...\python\plugins\sp_ai_assistant

旧版目录也会检测:
...\Documents\Allegorithmic\Substance Painter\python\plugins

安装不会写入 Painter 安装程序目录，也不会删除其他插件。

安装后启动 Painter，在 Python 菜单中找到并启用 SP AI Assistant。插件会显示 Dock 面板并提供运行环境自检。
